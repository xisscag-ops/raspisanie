# Расписание НГИЭУ (С-25ИО) — Android

Нативное Android-приложение (Kotlin + Jetpack Compose + Material 3) для просмотра расписания группы **С-25ИО** Княгининского университета (НГИЭУ).

## Возможности

- **Данные из открытого API НГИЭУ** (`https://230352-2.vm.clodo.ru/api/v2/`) без ключей и авторизации:
  - динамическое определение `actorId` группы `С-25ИО` через `Actors/Get?isStudent=true` (с резервным ID);
  - загрузка расписания через `Schedule/Get?actorId=...`;
  - автоматическое определение текущей недели (верхняя / нижняя) через `WeekType/Get?date=YYYY-MM-DD`.
- **Удобная навигация:**
  - полоса дней недели (`Пн–Сб`) с точками-индикаторами наличия пар и замен;
  - переключение режимов **«День»** и **«Вся неделя»**;
  - переключение верхней/нижней недели и пролистывание недель, кнопка быстрого возврата на **«Сегодня»**.
- **Живой баннер статуса пары:**
  - показывает текущую пару, прогресс-бар и сколько минут осталось до конца;
  - на перемене показывает время до следующей пары.
- **Подсветка замен (`ЗАМЕНА`)** и цветовые метки типов занятий (Лекция, Практика, Лаб. работа, Экзамен, Консультация).
- **Оффлайн-кэш:** мгновенный запуск из локального кэша с фоновым обновлением и Pull-to-Refresh.
- **Дополнительно:** шторка со звонками (1–7 пары) и переключением темы (Системная / Светлая / Тёмная).

## Как собрать APK

### Вариант 1: Автосборка на GitHub Actions
В репозитории настроен workflow `.github/workflows/android.yml`. При пуше в `main` или `arena/**` (или ручном запуске `workflow_dispatch` во вкладке **Actions** на GitHub):
1. Прогоняются unit-тесты (`./gradlew testDebugUnitTest`).
2. Собирается APK (`./gradlew assembleDebug`).
3. Готовый файл `ngieu-c25io-schedule-debug-apk` появляется в разделе **Artifacts** завершённого запуска.

### Вариант 2: Локально в Android Studio / через CLI
Требуется JDK 17 и Android SDK (compileSdk 36):
```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
```
Готовый APK будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.

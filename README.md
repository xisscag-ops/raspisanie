# Расписание НГИЭУ (С-25ИО) — Android

Нативное Android-приложение (Kotlin + Jetpack Compose + Material 3) для просмотра расписания группы **С-25ИО** Княгининского университета (НГИЭУ).

## Возможности

- **Данные из открытого API НГИЭУ** (`https://schedule.ngieu.ru/api/v2/`) без ключей и авторизации:
  - динамическое определение `actorId` группы `С-25ИО` через `Actors/Get?isStudent=true` (с резервным ID);
  - загрузка расписания через `Schedule/Get?actorId=...`;
  - автоматическое определение текущей недели (верхняя / нижняя) через `WeekType/Get?date=YYYY-MM-DD`.
- **Дизайн Neon Glass и навигация:**
  - стеклянные карточки (glassmorphism) на тёмно-неоновом градиентном фоне с левым таймлайном пар и векторными иконками из UI-кита;
  - полоса дней недели (`Пн–Сб`) с точками-индикаторами наличия пар и замен;
  - плавные свайпы влево и вправо по дням (во вкладке **«Главная»**) и по неделям (во вкладке **«Неделя»**);
  - парящая нижняя панель навигации (`Главная`, `Неделя`, `Звонки`, `Настройки`) и раскрывающийся поиск по предметам, преподавателям и аудиториям;
  - выбор верхней/нижней недели и пролистывание недель, кнопка быстрого возврата на **«Сегодня»**.
- **Живой баннер статуса пары:**
  - раскрывающаяся капсула прогресса дня (`X / N пар сегодня`) с градиентным прогресс-баром;
  - показывает текущую пару и сколько минут осталось до конца, либо время до следующей пары на перемене.
- **Подсветка замен (`ЗАМЕНА`)** и цветовые метки типов занятий (Лекция, Практика, Лаб. работа, Экзамен, Консультация).
- **Оффлайн-кэш:** мгновенный запуск из локального кэша с фоновым обновлением и Pull-to-Refresh.
- **Дополнительно:** расписание звонков (1–7 пары) и переключение темы (**Неон** по умолчанию / Система / Светлая / Тёмная).

## Как собрать APK

### Вариант 1: Готовый APK с GitHub (Releases и Actions)
В репозитории настроен workflow `.github/workflows/android.yml`.
- При каждом пуше в `main` автоматически создаётся **GitHub Release** (раздел **Releases** → **Latest**) с подписанным APK-файлом **`ngieu-c25io-schedule-v1.0.<номер>.apk`**, который можно скачать на телефон и установить поверх предыдущей версии **без удаления старого приложения** (сохраняется кэш и настройки темы).
- На любой ветке (`main`, `arena/**`) и в PR также запускаются тесты (`./gradlew testDebugUnitTest`), сборка `./gradlew assembleRelease` с постоянной подписью (`app/signing/ngieu-raspisanie.p12`) и загрузка артефакта `ngieu-c25io-schedule-apk` в разделе **Actions**.

### Вариант 2: Локально в Android Studio / через CLI
Требуется JDK 17 и Android SDK (compileSdk 36):
```bash
./gradlew testDebugUnitTest
./gradlew assembleRelease
```
Готовый подписанный APK будет находиться в `app/build/outputs/apk/release/app-release.apk`.
